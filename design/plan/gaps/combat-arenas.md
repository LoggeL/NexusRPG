# Lücken: combat-arenas

- **Status „Nass“ fehlt** (`StatusId` in contracts.ts). world.md braucht ihn für `boss-nagbert` (P2: alle „Nass“, Strom auf Nass), `boss-zuendholz` (Löschtank: „Nass“, Pz −3) und die Kanal-Rinnen. Jetzt: `arena-kanal` hat `hazard: { damage: 2 }` ohne Status. Vorschlag: `nass` als StatusId (Strom-/Hackschaden +50 %, löscht „Brennt“), dann `arena-kanal.hazard.status = 'nass'`.
- **Nur ein Gefahrentyp je Arena** (`ArenaDef.hazard`). `arena-hafen-oelfaesser` bräuchte Öl (rutschig) und Feuer getrennt, `arena-labor-altlager` Löschtanks als zerstörbare Objekte. Vorschlag: `hazards: Record<char, {status?, damage?}>` mit weiteren Zeichen (z. B. 'o' Öl, 'w' Wasser) oder zerstörbare Objekte (`props: { cell, hp, onBreak }`) für Löschtank/Fässerturm.
- **Erhöhte Felder / Abgrund** für `arena-hafen-kran` (Variante „erhöht“): Löcher im Gitter sind jetzt '#' (unbegehbar). Schubsen/Rückstoß in ein Loch hätte keinen Effekt. Vorschlag: Zeichen 'X' = Abgrund (nicht begehbar, blockiert keine Sicht, Rückstoß hinein = K.O. für Gegner ohne Moral).
- `boss-jimmy` **Fässerturm (3 Ölfelder)**: Arena-Layout ist fest; neue '~'-Felder im Kampf bräuchte die Engine (z. B. `BattleState.extraHazards`).
- Arena-Varianten als eigene IDs: `arena-hafen-kran`, `arena-hafen-ring`, `arena-hafen-oelfaesser`, `arena-labor-ruine`, `arena-labor-penthouse`, `arena-labor-altlager`, `arena-labor-quantum`. Begegnungen sollten diese IDs nutzen: `enc-kran-falke` → `arena-hafen-kran`, `enc-hafen-jimmy` → `arena-hafen-oelfaesser`, `enc-ring-xion` → `arena-hafen-ring`, `enc-penthouse-drohnen` → `arena-labor-penthouse` (Ausgang: Felder [11,3]/[11,1] rechts), `enc-ruine-waechter`/`enc-ruine-pluenderer` → `arena-labor-ruine`, `enc-altlager-zuendholz` → `arena-labor-altlager`, `enc-campus-patrouille` → `arena-labor-quantum`.
