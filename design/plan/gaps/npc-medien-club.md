# Lücken: Figuren Ripper, Barkeeper, Kameramann, Collin, Delya (`content/parts/npc-medien-club/`)

1. **Söldnerlohn pro Tag (Ripper, world.md §4.6 „30 Cr/Tag“).** Es gibt keinen Tageswechsel-Haken, der Begleitern Kosten abzieht. Jetzt: Anheuern im Tagesgespräch kostet einmalig 30 Cr (`{ credits: -30 }`, `{ recruit: 'ripper' }`), Entlassen per Wahl. Vorschlag: `CompanionDef.dailyFee?: number` – beim Tageswechsel abbuchen, bei zu wenig Geld automatisch `dismiss`.
2. **Begleiter mit Einsatzgrenzen (Barkeeper).** world.md §11.2: nur Club- und Neon-Gassen-Kämpfe, nicht Fr/Sa nachts. Kein Feld dafür. Jetzt: frei einsetzbar ab ♥8; Dialog nennt die Grenze. Vorschlag: `CompanionDef.availableWhen?: Condition` (Party-Prüfung vor dem Kampf, z. B. `{ all: [{ any: [{ visited… }] }, { not: { all: [{ weekday: ['fr','sa'] }, { time: 'nacht' }] } }] }`) plus Kartenliste.
3. **Rabatt bei einem Händler (he-ripper-2, „−10 % Preise“).** ShopDef kennt keinen bedingten Preisnachlass. Gesetzt wird Flag `ripper_rabatt`. Vorschlag: `ShopDef.discounts?: { when: Condition; percent: number }[]`, Shop `ripper-praxis` mit `{ when: { flag: 'ripper_rabatt' }, percent: 10 }`.
4. **Flirts ab ♥6.** `{ romance: npc }` ist erst ab ♥8 wahr; eine Bedingung „Figur ist freigeschaltet“ ohne Herzschwelle fehlt. Collins Flirtzeilen hängen deshalb an `{ romance }` (Akt 1 erreicht ♥8). Vorschlag: `romanceEnabled: { romanceEnabled: NpcId }` (nur Freischaltung + Kennzeichen), dann Flirt-Pools ab `minHearts: 6`.
5. **„Bleib heute Nacht“ höchstens einmal pro Woche.** Kein Wochenzähler. Jetzt: Angebot nur freitags abends (`collin-bleib-heute-nacht`, Talk-Eintrag), dadurch faktisch 1×/Woche. Flags `collin-charleston_nacht` und `collin_nacht` werden beide gesetzt (welches die Crew-Kommentare abfragen, ist noch nicht vereinheitlicht).
6. **Fotomodus (he-kameramann-6).** Gesetzt wird Flag `fotomodus` (+ Meldung). Die Darstellung braucht eine Taste F/Fotofunktion, die bei diesem Flag aktiv wird; `pers-kameramann-ungeschminkt` (Quest-Agent) sollte dieselbe Flag-ID nutzen.
