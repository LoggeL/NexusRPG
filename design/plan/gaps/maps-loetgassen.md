# Lücken: Paket pkg-loetgassen (loetgassen, dantes-werkstatt, loetzinn-laden)

- **Taubenpost 1× pro Tag** (world.md §3.9 `akt-taubenpost`): Es gibt keine Bedingung „heute schon gemacht“ (Tages-Flags, die um 06:00 zurückgesetzt werden). Notbehelf: Jeder Brief kostet 3 Cr; Herzpunkte +10 pro gewonnenem Minispiel. Vorschlag: Bedingung `{ todayNot: '<key>' }` bzw. Effekt `{ setDayFlag }` in der Engine, dann Taubenpost-Wahl damit sperren. Ort: `parts/maps/loetgassen.ts` Dialog `dlg-loetgassen-taubenpost`. Flag `taubenpost_frueh` (Taube gefangen, gc-153) hat noch keine Wirkung („einen Tag früher“).
- **Wäschehof-Check** `[Straße 4]`: world.md nennt keine gc-ID. Notbehelf: Inline-Check `gc-loet-waeschehof` (Straße 4, Tags einschuechtern/welt) im Dialog `dlg-loetgassen-waeschehof`; Checks-Agent kann ihn durch eine echte gc-ID ersetzen. Wege ohne Check: helfen (30 Min.), ab Tag 2, `[Gosse]`.
- **Shop-ID Dante**: Plan nennt `dante-werkstatt`, `parts/system/shops.ts` definiert `dantes-werkstatt`. Hotspot-ID bleibt `dante-werkstatt`, verweist auf Shop `dantes-werkstatt`.
- **Vex' Unterschlupf Kurierbude**: `loetgassen.shelter = { entry: 'aufwachen', when: { playerIs: 'vex' } }` plus Schlaf-Hotspot `kurierbude-schlafen` (A/N). Ob `campaign.sleep()` über einen Hotspot auf einer Zonenkarte dort aufwachen lässt (statt im Crew-Quartier), entscheidet die Engine (HomeDef). Vorschlag: Schlafen per Hotspot weckt am `shelter.entry` der aktuellen Karte.
- **Quest-Hotspots bewusst NICHT angelegt** (damit die Quest-Agenten die Plan-IDs ohne Kollision per mapAdditions setzen können): `hinterhof-studio` (side-thai-chi), `stellwerk-loet` (gc-50, side-uebliche-verspaetung), Fenster-Lauschen gc-20 (main-1-dante, Spot `werkstatt-fenster`), `faxgeraet` (gc-18 / side-eingehendes-fax), `plattenregal` (side-schallplatten), `kabelrolle` (gc-120, side-strom-fuer-die-rohre). Die Zone hat dort nur Look-Hotspots mit eigenen IDs (`hinterhof-studio-ansehen`, `stellwerk-kasten`, `werkstatt-fenster-ansehen`, `faxgeraet-ansehen`, `plattenregal-ansehen`, `kabelrolle-ansehen`).
- **Dachfirst `schallplatte-03`**: „nur über Dachsprung gc-150 oder Item“. Das Dach ist auch über die Feuertreppe begehbar (Opa Gurrmann muss hoch); der First selbst ist ein Check-Hotspot `gc-150` bzw. frei mit `beine-sprungfedern`/`arme-greifhaken`/`dachlaeuferin`.
- **Dachsprung-Ausgang mit Gegenstand**: ExitDef kennt nur `when` UND `check`. Deshalb zwei Ausgänge am selben Rechteck: `dachsprung-neon-gasse` (Check gc-150, wenn keine Sprungkraft) und `dachsprung-neon-gasse-frei` (Sprungfedern/Greifhaken/dachlaeuferin).
- **Aussichtspunkt**: Hotspot `aussicht-taubenschlag` gibt 20 XP, setzt Flag `aussicht_loetgassen` und `markSeen('aussicht-loetgassen')`. Das Aufdecken der Zonenkarte und die Sammelobjekt-Silhouetten muss die Engine aus diesem Flag lesen.
- **Kurierbude-Dekostufen** hängen an `seen`-IDs der Romanze-Cutscenes (`rom-vexaria-morgen`, `rom-vexaria-funkmast`, `rom-aria-stirn`, `rom-vexaria-konzert`) und am Flag `vexaria_kronkorken`. Heißen die Cutscenes anders, bitte die `when` in `BUDE_STUFEN` (loetgassen.ts) anpassen.
- **Interieur-Bilder**: Codex liefert 3:2; die Rohbilder `dantes-werkstatt.png`/`loetzinn-laden.png` sind oben/unten um 64 px dunkel aufgefüllt (4:3) statt beschnitten, damit nichts am Rand fehlt.
- **map_overlay.py** zeichnet nur 640×360 (alter Maßstab); für 1536×1024 zeigt die Vorschau nur den linken oberen Ausschnitt. Vorschlag: Größe aus `map.size` lesen.
